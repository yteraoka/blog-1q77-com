2年7カ月ほど利用してきたスマートロックの SESAME 5 が突然機能しなくなりました。
スマホでの操作や SESAME FACE との連携で反応はしてカチカチと小さな音を立てるけれどもサムターンは回らない状況でした。

電池切れかな？と思って電池を買って交換してみましたが変化なしでした。
ちなみに CANDYHOUSE さんでは電池も売ってて他で買うよりずっと安です。

[CR2](https://jp.candyhouse.co/products/%E3%82%BB%E3%82%B5%E3%83%9Fbot%E7%94%A8-cr2-%E9%9B%BB%E6%B1%A0-%E3%83%90%E3%83%83%E3%83%86%E3%83%AA%E3%83%BC) も [CR123A](https://jp.candyhouse.co/products/new_%E5%88%9D%E4%BB%A3%E3%82%BB%E3%82%B5%E3%83%9F-%E3%82%BB%E3%82%B5%E3%83%9Fmini-3-4-%E3%82%B5%E3%82%A4%E3%82%AF%E3%83%AB%E5%85%B1%E9%80%9A-%E9%AB%98%E5%AE%B9%E9%87%8F1800mah%E3%81%AEcr123a-%E9%9B%BB%E6%B1%A0-%E3%83%90%E3%83%83%E3%83%86%E3%83%AA%E3%83%BC) も税込み163円です。

スマートロック製品は沢山販売されていますが SESAME は大変コスパが良いです。
本体も公式サイトで買うのが安いです。[SESAME 5](https://jp.candyhouse.co/products/sesame5) はセールで税込み3,828円です。

事象について検索してみたら同じような事象の人がモーターの故障だということを書かれていました。
さらに CANDYHOUSE さんは利用者が自分で交換できるように[モーターだけも販売されていました](https://jp.candyhouse.co/products/%E3%83%A2%E3%83%BC%E3%82%BF%E3%83%BC)。しかも税込み218円ぽっきり。
早速購入して交換しました。ここでは交換手順をメモっておきます。

## SESAME 5 をドアから外す

修理用に購入したモーターと並べてみました。モーターはミニ四駆のモーターよりもずっと小さいものでした。

{{< figure src="sesame5-01.jpg" alt="モーターのサイズ感" >}}

## カバーを外す

カバーを開けるには細めのプラスドライバーで細い部分の長さがそこそこ必要です。コンビニなんかにも売ってるドライバーセットの細いやつが使えました。

{{< figure src="sesame5-02.jpg" alt="ドライバーの長さ" >}}

2箇所のネジを緩めてカバーを外します。

{{< figure src="sesame5-03.jpg" alt="ドライバーの長さ" >}}

モーターが確認できました。

{{< figure src="sesame5-04.jpg" alt="カバーを外したところ。モーターの位置を確認" >}}

## モーターを取り外す

モーターのコネクタを外す。

{{< figure src="sesame5-05.jpg" alt="モーターのコネクタを外したところ" >}}

モーターはまっすぐ引っ張れば抜けました。

{{< figure src="sesame5-06.jpg" alt="モーターを本体から外したところ" >}}

モーターにネジ止めされているパーツを外します。2箇所のネジを緩めるだけです。

{{< figure src="sesame5-07.jpg" alt="ネジ位置確認" >}}

外れました。

{{< figure src="sesame5-08.jpg" alt="モーターにネジ止めされてるパーツを外したところ" >}}

## 新しいモーターと交換

新しいモーターを取り付けます。

{{< figure src="sesame5-09.jpg" alt="新しいモーターにパーツをネジ止めしたところ" >}}

モーターを本体に取り付けます。先ほどのパーツの先に伸びている棒は断面が円ではなく四角に近くて、角度を合わせて差し込みます。その後、電源用のコネクタを挿して蓋をすれば交換完了です。

{{< figure src="sesame5-10.jpg" alt="新しいモーターにパーツをネジ止めしたところ" >}}

無事に元通りに機能するようになりました。パーツも良心的な価格で提供していただいている CANDYHOUSE さんありがとうございます。
